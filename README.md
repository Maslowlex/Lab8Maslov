## 1. Алгоритм и блок-схема

### Алгоритм решения
1. **НАЧАЛО**
2. Объявление переменной `n` (целое число) и `sum` (вещественное число, начальное значение 0.0).
3. Вывод "Введите значение n: ".
4. Ввод значения `n` с клавиатуры.
5. Проверка: если `n < 1`, вывод ошибки и завершение.
6. Цикл `for` (переменная `i` от 1 до `n`):
   - Вычисление знаменателя: `denominator = 2 * i + 1`.
   - Вычисление дроби: `term = 1.0 / (denominator * denominator)`.
   - Накопление суммы: `sum = sum + term`.
7. Вывод результата `sum`.
8. **КОНЕЦ**

### 📊 Блок-схема (Описание для построения)
*   **Овал (Начало)**
    *   *Стрелка вниз*
*   **Параллелограмм (Ввод данных)**: Ввод `n`
    *   *Стрелка вниз*
*   **Ромб (Условие)**: `n < 1 ?`
    *   **Да** ➔ *Стрелка вправо* ➔ **Параллелограмм (Вывод)**: "Ошибка" ➔ *Стрелка вниз к Концу*.
    *   **Нет** ➔ *Стрелка вниз*
*   **Прямоугольник (Процесс)**: `sum = 0.0`, `i = 1`
    *   *Стрелка вниз*
*   **Шестиугольник (Цикл/Условие)**: `i <= n ?`
    *   **Нет** ➔ *Стрелка вправо и вниз* к выводу результата.
    *   **Да** ➔ *Стрелка вниз*
        *   **Прямоугольник (Процесс)**: `term = 1.0 / ((2*i + 1) * (2*i + 1))`
        *   **Прямоугольник (Процесс)**: `sum = sum + term`
        *   **Прямоугольник (Процесс)**: `i = i + 1`
        *   *Стрелка вверх обратно к шестиугольнику (Цикл)*
*   **Параллелограмм (Вывод данных)**: Вывод `sum`
    *   *Стрелка вниз*
*   **Овал (Конец)**
